# Need for Speed: Most Wanted (2005) H-Shifter Support

A maintained fork of [MW2005-HShifter](https://github.com/x0reaxeax/MW2005-HShifter) by x0reaxeax.

## About This Fork

This fork contains stability modifications for use with the [RealManual](https://github.com/Eradinelle/RealManual) project.

In the RealManual implementation, this plugin provides direct in-game gear selection while RealManual script handles the higher-level transmission, clutch, handbrake, stall, synchronization, and input-management logic.

This fork is not intended to be used independently from RealManual, although it can be if you just want MW2005-HShifter functionality.

## Compatibility

**Only Need for Speed: Most Wanted (2005) 1.3 Black Edition is supported.**
